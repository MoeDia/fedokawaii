# tests/static/fixtures/programs.txt — where each program the desktop runs comes from, on a
# fresh Fedora 44 Server "Minimal Install" after setup. tests/static/test_deps.sh holds every
# program found in the scripts and configs against this list (deps.py says how it reads them).
#
#   PROGRAM   KIND      WHAT
#   manifest  PACKAGE   lib/manifest.sh installs PACKAGE, which has the program (the test
#                       checks PACKAGE is in manifest_all)
#   minimal   PACKAGE   a Minimal Install has PACKAGE: in comps' @core, or a hard dependency of
#                       something there (the chain is in the comment). Listed in the manifest,
#                       it must say manifest instead (the test checks that too)
#   dep       PACKAGE BY  not on a Minimal Install, but a hard dependency of BY, a manifest
#                       package (the test checks BY is in manifest_all): there, though
#                       nothing lists it
#   upstream  -         a binary of lib/upstream.sh's table (checked)
#   built     NAME      setup.sh or theme.sh builds or installs it (NAME: what they call it)
#   optional  -         installed by nothing on purpose: every call must be guarded
#                       (command -v, or a fallback after ||)
# The desktop's own programs (bin/, system/) need no line.
#
# Package → file: mdapi.fedoraproject.org/f44/files/<package> (checked 2026-10-16 where it
# says "f44"); @core: comps "Minimal Install" = core (+ its defaults), checked against
# forge.fedoraproject.org/releng/fedora-comps comps-f44.xml.in on 2026-10-16; the chains: mdapi requires.
