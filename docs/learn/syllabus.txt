# docs/learn/syllabus.txt — the lessons, in the order that teaches best: the one place that order
# is written. tools/learn-pieces.py cuts docs/fedokawaii-learn.md by it into pieces/NNN-ID.md; a
# section of the book in no lesson, or in two, stops it. Progress (kawa-learn) is kept by a
# lesson's ID: reorder and rename at will, but keep an ID once it is out.
#
#   part ID | NAME | ICON                  a tab of the lessons window
#   chapter N ID | NAME | ICON [| needs N N …]   a heading; needs: what the book's "You need" does
#                                           not say (the programs' chapters have none)
#   ID | TITLE | WHAT… [| ~MINUTES]         a lesson of that chapter (~: when the words and the code
#                                           do not say how long it takes: a checkpoint project)
#   x | y                                   the chapter's exercises: x its ★ and ★★ (a lesson called
#                                           practice), y its ★★★ and ★★★★ (projects — optional:
#                                           when you have the time, never counted, never "next")
#
# WHAT: 0 the chapter's opening · 1 2 … its ## N.1 N.2 … · x y as above · 0/2 the second part of a
# section the book cuts with <!-- cut --> · PI … PVI a part's opening · how the book's first
# pages · 66.0/1 any other chapter's section, in full.
#
# The order is the book's but for: the plan first (nobody reads a plan last); the files before the
# shell, moving before finding; the programs' daily ones first; working with AI after Python
# (chapter 69 needs chapter 47, 67 is better after 45) and before Rust, so Rust is learnt with
# what it teaches.
