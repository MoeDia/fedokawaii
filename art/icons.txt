# art/icons.txt — the desktop's own pixel icons, one block per icon.
# Drawn for the 11 px Departure Mono grid: '#' = pixel, '.' = empty.
#
# A block starts with "@name", optionally followed by settings:
#   adv=N   advance in pixels (default: width + 4, so the icon has 2 px of air each side)
#   x=N     where the drawing starts, in pixels from the pen (default: centred in adv)
# Heights are even and every icon is centred on the text's middle (y = 4 px), so it sits
# on whole pixels next to Departure Mono at 11 px, 22 px, 33 px…
#
# tools/build-icons.py turns this file into
#   configs/home/.local/share/fonts/SumiIcons.ttf   font "Sumi Icons", U+FE000 onwards in
#                                                   this order (Supplementary Private Use
#                                                   Area A, clear of every Nerd Font)
#   configs/home/.config/fedokawaii/icons.sh        ICON_<NAME> variables for the scripts
# Append new icons at the end: inserting one in the middle renumbers the ones after it.
