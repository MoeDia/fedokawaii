# art/icons.txt — the desktop's own pixel icons, one block per icon.
# Drawn for Sumi UI's 16 px grid (Shinonome Gothic 16 Bold): '#' = pixel, '.' = empty.
# Weighted as its letters are: upright strokes 2 px, horizontal ones 1 px; most icons 14 × 14.
#
# A block starts with "@name", optionally followed by settings:
#   adv=N   advance in pixels (default: the width rounded up to whole 8 px columns of the
#           font, so a 14 or 15 px icon takes two, with its air shared either side)
#   x=N     where the drawing starts, in pixels from the pen (default: centred in adv)
# Two kinds, both on whole pixels next to Sumi UI at 16 px, 32 px, 48 px…:
#   even × even      resting on the baseline (its bottom row on it), 14 rows the capitals'
#                    13 and one more — icons beside words
#   odd × 15 rows    "seal-sized": in place of a 16 × 16 kanji, as tall as the font's kanji
#                    less a row and standing as they do, so in the bar's buttons kanji and
#                    icons alike sit alike — the torii, the layouts, the joystick, the cat
#
# tools/build-icons.py turns this file into
#   configs/home/.local/share/fonts/SumiIcons.ttf       font "Sumi Icons", U+FE000 onwards
#                                                       in this order (Supplementary Private
#                                                       Use Area A, clear of every Nerd Font)
#   configs/home/.local/share/fonts/SumiIconsTerm.ttf   "Sumi Icons Term": the same, for the
#                                                       terminal's Sumi Term at 20 px
#   configs/home/.config/fedokawaii/icons.sh            ICON_<NAME> variables for the scripts
# Append new icons at the end: inserting one in the middle renumbers the ones after it.
