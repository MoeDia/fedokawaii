# art/cursors.txt — the mouse pointers, drawn pixel by pixel (tools/build-cursors.py).
# Each pointer: "@name hot=X,Y [halo]", then its rows. At 1:1 every character is one
# screen pixel (24 px pointers, the desktop's 1x pixel scale); the 48 px set for 2x
# screens is the same drawing with every pixel doubled — no smoothing anywhere.
#   .  clear     K  ink  #0f0e0c     W  paper  #ece3cc     R  vermilion  #d0583a
# "halo": the drawing is a line in ink (and vermilion); a 1-pixel paper rim is added all
# round, so it reads on ink and on paper alike. Without it, the drawing has its own rim.
