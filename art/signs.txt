# art/signs.txt — the signs Sumi UI and Sumi Term draw themselves (tools/build-fonts.py).
#
# The faces draw these two cells wide (Japanese text: an arrow, a circle, a dash takes a
# kanji's room) or not at all; a terminal and kawa-panel give each one cell. Unifont has
# them one cell wide but drawn for 8 × 16 at a lighter weight: beside the 20 px terminal
# face they came out small and thin. So the ones the desktop shows are drawn here, for each
# face's cell, in its weight (upright strokes two pixels, the rest one), on its lines:
#   ui    8 × 16: the line rows 0–15, baseline under row 13, small letters rows 5–13,
#                 capitals 1–13, the minus on row 7, the full stop rows 12–13
#   term 10 × 20: the line rows 1–20, baseline under row 17, small letters rows 8–17,
#                 capitals 4–17, the minus on row 10, the full stop rows 15–17
# "= SIGN FACE ROW": the drawing below starts on that row of the line; '#' ink, '.' paper,
# each line exactly the cell's width. The rightmost column stays paper (the next letter's
# air), except where a sign is meant to run on (—, the box lines are foot's own).
