# art/firealpaca-icons.txt — our drawing of every picture FireAlpaca shows in its tool strip, its bars
# and its lists: one block per file of the program's own resources (":/images/NAME.png"), the same
# name and the same size, so nothing else changes. '#' = pixel, '.' = empty; one ink: a mask, painted in
# its state's ink where it is shown (src/kawa-firealpaca). Woodblock: masses solid, details knocked out,
# a pixel of air all round where the size allows. tools/build-firealpaca.py builds them to
# configs/home/.local/share/fedokawaii/firealpaca/icons/NAME.png.
