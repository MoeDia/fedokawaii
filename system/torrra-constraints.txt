# system/torrra-constraints.txt — the versions torrra 2.5.1 was released with, for pip
# (`uv tool install --constraints THIS`, setup.sh's torrra_up). torrra itself is pinned in
# lib/upstream.sh (TORRRA_VERSION); its own requirements are open-ended (textual>=6.5.0 …),
# so without these a fresh install would take whatever Textual, Rich or httpx is newest that
# day — and Textual changes its interface with every major version.
# Made from torrra v2.5.1's uv.lock: its runtime dependencies, followed through, for Linux
# and Python 3.13. Two are left free on purpose: libtorrent (the part that talks to the
# network: update moves it to its newest) and certifi (the list of trusted certificate
# authorities: data, best current). A new TORRRA_VERSION comes with a new list.
# One lift past the lock: Textual 8.2.8 (torrra asks for >=6.5.0) — kawa-torrra draws torrra
# in its ansi-dark theme, which Textual has only since 8.2; on 8.0.1 torrra refused that
# name and quit before its window drew (the Torrents entry that opened nothing). torrra_up
# reinstalls whenever what is installed is not exactly this list.
