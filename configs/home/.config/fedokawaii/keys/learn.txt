── lessons: the list ──────────────────────────────────────────────
↑ / ↓                   the lesson before / after
← / → / Tab             the part before / after

/                       find in every lesson's words (Esc ends it)

↑ / ↓ / the wheel       a line
Space / PgUp / PgDn     a page

s                       the solutions, under each exercise
← / →                   the lesson before / after
Esc / q                 back to the list
