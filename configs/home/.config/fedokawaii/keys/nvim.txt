# nvim 0.12.6 with his own config; the leader key is Space
# command: nvim --version
# command: nvim_get_keymap in a pty over this repo's config (r28-f23), a Python file and a Rust file
# source: /usr/share/nvim/runtime/doc/index.txt, lsp.txt, vim_diff.txt (nvim 0.12.6: the core keys, g r n and the rest)
# ours: configs/home/.config/nvim/lua/config/keymaps.lua, clipboard.lua (y, p, P), lua/plugins/editor.lua (] h, [ h), lua/plugins/debug.lua (Space d), after/ftplugin/ (Space r)
── nvim: basics ───────────────────────────────────────────────────
i / a / o               type before / after / on a new line below
Esc                     back to normal mode (and clear the search marks)
h j k l                 left, down, up, right (w / b: a word on / back)
g g / G                 top / bottom of the file
u / Ctrl+R              undo / redo
d d / y y               cut / copy a line (a copy also goes to the desktop)
p                       paste the newest copy, from here or the desktop
Ctrl+S                  save
── nvim: find ─────────────────────────────────────────────────────
Space, then wait        every Space key, as a menu (which-key)
Space Space             find a file in the project
Space /                 search the project's text (grep)
Space ,                 switch between open buffers
Space e                 the file tree
Space f r / f h         recent files / neovim's help
Space f k / f d         every key / every problem, in a list
/ then n / N            search this file, next / previous result
── nvim: code ─────────────────────────────────────────────────────
Ctrl+N / Ctrl+Y         completion: the next word / take it
g d / g r r             go to the definition / list what uses it
K                       what it is (hover help)
g r a                   code action (a fix, an import)
g r n                   rename everywhere
g O                     this file's symbols
Space c f               format the file
] d / [ d               next / previous problem
g c c                   comment or uncomment the line (g c: a selection)
── nvim: windows, buffers, git ────────────────────────────────────
] b / [ b               next / previous buffer
Space b d               close this buffer
Ctrl+H / J / K / L      go to the window left / below / above / right
Space g g               lazygit, inside neovim
] h / [ h               next / previous changed block (git)
Space f t               a terminal under the code
Space l                 the plugins
Space q q               quit everything
── nvim: run, debug (Space r, d) ──────────────────────────────────
Space r f               run the file: uv run (Python) · cargo run (Rust)
Space r t               the tests: pytest (Python) · cargo test (Rust)
Space r r               the REPL, open or hide (Python)
Space r c               run the # %% cell (Python) · cargo check (Rust)
Space r l               run the line (Python) · cargo clippy (Rust)
Space r s               run the selection (Python, in visual mode)
Space d b / d c         debugger: set a breakpoint / run or continue
Space d n / d i / d o   debugger: next line / step in / step out
Space d u / d t         debugger: its panels / end it
